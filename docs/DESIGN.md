> 配套：[`ALGO.md`](./ALGO.md)（预测算法）、[`TECH.md`](./TECH.md)（技术实现）、[`IOS_PROMPT.md`](./IOS_PROMPT.md)（iOS 任务书）

## 0. 一句话原则

**这是给一个用户看自己设备电量的工具，不是作品集。** 所有像素都在传达数据：数字要大、时间要准、推断要标明、没数据要说清楚。不做装饰性渐变、不做入场动画、不做拟物。

四条硬规矩：

1. **只用本文列出的颜色**，不得新增色值（新增等于破坏跨端一致性）。
2. **层级靠字号与颜色，不靠卡片套卡片**。全站只有三层容器：页面 → `.panel` → `.card`。
3. **同一个事实必须在所有端长得一样**：`80%` 就是 `80%`，不写 `80 %`、`0.8`、`80 percent`。
4. **推断必须可见**。看板里没有「大概」「可能」这类词，只有明确的 `推测充电` / `推断` / `回归` / `~` 标记。

| `--green` | `#34d399` | 充电、上涨、正向 |

| 图 | 上 → 下 |

| 充入分布 | `rgba(52,211,153,.95)` → `rgba(16,185,129,.30)` |

## 4. 组件清单（照抄，不要发明新组件）

### 4.1 `.panel` —— 唯一的内容容器

```css
background:var(--card); border:1px solid var(--line); border-radius:16px;
padding:14px 14px 10px; margin-bottom:14px;
backdrop-filter:blur(10px); box-shadow:0 20px 50px -30px rgba(0,0,0,.9);
```

标题行结构固定：`标题 <em>副标</em> <span class="seg">…</span>`，其中 `em` 承载「口径说明」，`seg` 靠 `margin-left:auto` 推到最右。

### 4.2 `.card` —— 设备卡片（只在设备总览用）

自上而下：名称 → 大数字 `%` → 说明行（`.mt`，多行）→ 底部 3px 进度条。

说明行是**多行**结构，顺序不许改：

```
电量 hh:mm · 充电中 · 已充 49 分      ← 第一行：电量时间 + 充电状态 + 已充时长
链路 hh:mm                            ← 第二行：采集链路最后活动
链路正常 · 电量 45 分 未变            ← 第三行（可选）：链路活着但电量没动
24h 变化 +3% · 采样 342 条            ← 第四行：变化量与样本量
掉电 2.56 %/h · 满电约 39 时          ← 第五行：速率与续航
```

`.card.stale`（链路 ≥2h 无更新）表现：描边变 `rgba(251,191,36,.32)`，大数字 `opacity:.42`，进度条 `opacity:.25`。**不改文字颜色**，靠透明度表达「失效」。

### 4.3 `.stats` —— 统计面板

两列网格，每项一行「标签（左，muted）+ 数值（右，白）」：

```css
display:grid; grid-template-columns:1fr 1fr; gap:8px 12px; font-size:.74rem;
border-bottom:1px dashed rgba(120,150,255,.12); padding-bottom:5px;
```

多设备时插入 `.statgrp` 分组行：`grid-column:1/-1`，行首 7px 色点 + 设备名，右侧「充满电后 N 点」。

### 4.4 `.seg` —— 二选一切换（v11.5）

```css
.seg{margin-left:auto;display:inline-flex;border:1px solid var(--line);
     border-radius:9px;overflow:hidden;align-self:center}
.seg button{font:inherit;font-size:.66rem;background:transparent;border:0;
            color:var(--muted);padding:2px 9px;cursor:pointer}
.seg button.on{background:rgba(59,130,246,.22);color:#dbeafe}
```

这是**唯一允许的分段控件样式**：不加阴影、不做胶囊、不做滑动指示器。切模式不重新请求数据。

### 4.5 其他原子

| 类 | 用途 | 关键点 |
|---|---|---|
| `.warn` | 警示文字 | `#fbbf24`，只用于「链路已停」「剔噪 N」 |
| `.hint` | 弱提示 | `#94a3b8`，只用于「电量未变」这类阳性说明 |
| `.drop` / `.up` | 掉电红 / 上涨绿 | 不得互换 |
| `.mod` | 标识符小块 | 等宽 + `rgba(148,163,184,.14)` 底 + `4px` 圆角 |
| `.tag` | 图例内小标签 | 如「稀疏」，`.6rem` + `1px` 描边 |
| `.dot` | 7px 状态点 | 绿=充电、红=掉电、蓝=持平 |
| `.empty` | 空态 | `--muted`，一句话说清「等什么」 |
| `.tip` | canvas tooltip | `rgba(8,12,22,.95)` 底 + 蓝描边 + `9px` 圆角，`white-space:nowrap` |
| `.tblwrap` | 表格滚动区 | `max-height:340px`，表头 `sticky` 且必须给不透明底色 `#101728` |

## 5. 布局

- 内容最大宽 `1080px` 居中；页面内边距 `18px 14px 42px`。
- 设备卡片网格：`repeat(auto-fill, minmax(158px,1fr))`，间距 `10px`。
- 双面板：`grid-template-columns:1fr 1fr`，间距 `14px`；`max-width:760px` 时改单列。
- 图表 canvas 靠 `data-h` 给高度（曲线 240、分布 168），宽度随容器自适应，用 `touch-action:pan-y` 允许纵向滚动手势。
- 表头 `sticky` 必须配不透明底色，否则滚动时会看穿。

## 6. 状态矩阵（每个组件都要覆盖）

| 状态 | 触发 | 表现 | 禁止 |
|---|---|---|---|
| 正常 | 数据新鲜 | 正常配色 | — |
| 链路已停 | `now - linkTs >= 2h` | 卡片 `.stale` +「X 没有任何上报，进程可能被冻结」 | 显示红色报错条 |
| 电量未变 | `stillH >= 2h` 但链路正常 | `.hint`「链路正常 · 电量 X 未变」 | 判定为设备离线 |
| 无数据 | `hist` 为空 | `还没有任何设备键，等客户端上报后自动出现。` / `暂无采样，等下一次上报。` | 画空坐标轴 |
| 加载失败 | fetch 异常 | `加载失败：<原因>` 写在副标位置 | 弹窗、Toast |
| 稀疏设备 | `sparseOf` 命中 | 图例加「稀疏」标签，默认不画不统计 | 直接隐藏设备行 |
| 未充电 | 无 open 段 | 统计面板「状态：未在充电」，速率「—」 | 显示 `0 %/h` |
| 已满电 | `last.l >= 100` | 「预计充满：已充满」 | 显示 `0 分` |
| 推测充电 | 段已开但 `inf`（设备未上报 `c`，靠上涨推断） | 「推测充电」`#5eead4` | 直接标成「充电中」 |

**空态文案必须是「说清在等什么」，不是「暂无数据」。**

## 7. 文案规范

| 规则 | 正例 | 反例 |
|---|---|---|
| 单位紧跟数字 | `80%` `36.63 %/h` | `80 %`、`36.63%/ 小时` |
| 速率单位统一 `%/h` | `2.56 %/h` | `0.0256/h` |
| 时长用中文单位 | `49 分` `2 时 30 分` `3 天 4 时` | `49min`、`2.5h` |
| 无值用长破折号 | 文字位 `—`，大数字位 `--` | `N/A`、`null`、半角单个 `-` |
| 推断必须标注 | `推测充电`、`推断`、`回归`、`~` | 把推断值当事实 |
| 时间只写 `hh:mm` | `链路 10:53` | `链路 今天上午 10 点 53 分` |
| 术语固定 | 电量 / 链路 / 掉电 / 充入 / 采样 / 已充电多久 | 电流、电池余量、连接状态 |
| 不承诺实时 | 「每 60 秒自动刷新」 | 「实时同步」「秒级更新」 |
| 不出现「我」「你」 | 「进程可能被冻结」 | 「你的设备可能冻住了」 |

数字精度：速率保留 **2 位小数**；百分比取整；ETA 走 `fmtDur`（Web 没有把分钟圆到 5 的倍数，其他端也不许圆）。

## 8. 图表规范

| 项 | 规则 |
|---|---|
| 折线 | 2px，颜色取设备色；**跳变点断开且不画点** |
| 数据点 | 仅在点数 ≤ 60 时画，直径 3px |
| 坐标轴 | 只有底边一条 `rgba(120,150,255,.10)`，不画网格 |
| 轴标签 | `--muted` `11px`，X 轴每 6 小时一个刻度 |
| 柱状图 | 柱宽 `bw*0.7`，最小 2px，圆角 3px，贴底 |
| 空态 | 居中一行灰字，**不画空坐标轴** |
| tooltip | 三段：「时间区间 + 值 + 采样条数」 |

## 9. 端映射（Web → SwiftUI）

| Web | SwiftUI / Widget |
|---|---|
| `--bg` + 渐晕 | `ZStack` 底色 `#0b0f19` + `RadialGradient`（Widget 可省渐晕） |
| `.panel` | `RoundedRectangle(cornerRadius:16)` + `fill(card).overlay(stroke)` |
| `.card` | 圆角 14，同色系；大数字 `.system(size:26,weight:.semibold)` |
| `.stats` 两列 | `Grid(horizontalSpacing:12, verticalSpacing:8)` |
| `.seg` | 两个 `Button` 在 `HStack(spacing:0)` + `clipShape(RoundedRectangle(cornerRadius:9))`，选中底 `blue.opacity(0.22)` |
| `.warn` / `.hint` | `#fbbf24` / `#94a3b8` |
| canvas 曲线 | `Path` + `Canvas`（Widget 禁用 Swift Charts） |
| `.tip` | App 用浮层；**Widget 不做 tooltip** |

Widget 里必须砍掉：tooltip、`.seg`（切不了）、表格。**保留**：大数字、状态行、24h 曲线（大号）。

## 10. 禁止事项（「别自己乱画」的具体含义）

- ❌ 自创色板、自创渐变、Hero 大图、玻璃拟态以外的任何「美化」
- ❌ 圆角随便给（`8/12/20` 混用），或卡片套卡片套卡片
- ❌ 用 emoji 当图标（⚡️🔋 一律不许）；充电用文字「充电中」或单色 SF Symbol
- ❌ 阴影发光、彩色边框、呼吸动画、数字滚动动画
- ❌ 把「推测」画成事实，或直接标「充电中」
- ❌ 空态写「暂无数据」（必须说清在等什么）
- ❌ 单位与数字之间加空格、时长用 `min/h`、无值写 `N/A`
- ❌ 在 Widget 显示错误文本或红色感叹号（只能用缓存或空态）
- ❌ 为好看把 24 小时分布改成饼图/环形图（口径是「每小时桶」，饼图表达不了时间轴）
- ❌ **按电量数值自己做分色**（如 `>50` 绿 / `20–50` 橙 / `<20` 红）。Web 端电量数字**一律**用 `--txt`，颜色只表达「事件」：`--green` 充电中、`#5eead4` 推测充电、`--red` 掉电、`#fbbf24` 警示。电池没电不是错误，不该染红。
- ❌ 自创状态词（「电量稳定」「几乎不耗电」「在线/离线」）。状态词只有 §6 矩阵里那九种。
